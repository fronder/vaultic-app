# Vaultic — сайт

Публичные страницы приложения Vaultic: политика приватности, условия
использования и справка. Нужны для полей Privacy Policy URL и Support URL
в App Store Connect.

Страницы **сгенерированы**, править их здесь не нужно: тексты берутся из
`Localizable.strings` самого приложения, чтобы сайт и экраны внутри приложения
не разошлись. Меняйте строки в приложении и пересоберите:

    python3 tools/make_site.py <путь-к-этому-репозиторию>

Хостинг — GitHub Pages, ветка `main`, корень.
